# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in our repository](https://github.com/changesets/changesets).

We have a quick list of common questions to get you started engaging with this project in
[our documentation](https://github.com/changesets/changesets/blob/main/docs/common-questions.md).

## This repo (WTK-57)

CI has a `changeset` gate: any PR that changes versionable code must include a changeset, so no
user-facing change silently drops out of the changelog or version bump. Add one with `pnpm changeset`
(pick the bump level + summary).

If a change touches code but genuinely needs no release (comment/test-only, chore), commit an empty
changeset instead — `pnpm changeset add --empty` — which satisfies the gate without producing a
version bump. The empty changeset must be committed; the gate diffs committed history against `main`.

Merging changesets to `main` maintains a "Version Packages" PR that bumps `package.json` and updates
`CHANGELOG.md`. Merging that PR builds the platform binaries and cuts a GitHub Release tagged
`v<version>` — no manual workflow run.
